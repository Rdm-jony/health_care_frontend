# 🏥 Healthcare Frontend

**Healthcare Frontend** is a responsive and user-friendly web application built with **React**, **TailwindCSS**, and **TypeScript**. It serves as the frontend for a full-stack healthcare platform, allowing patients to browse doctors, book appointments, and manage their profiles seamlessly.

---

## 🌐 Live Demo

- **Frontend:** [https://health-care-frontend-ten.vercel.app](https://health-care-frontend-ten.vercel.app)  
- **Backend:** [https://health-care-beckend.vercel.app](https://health-care-beckend.vercel.app)

---

## 💻 Features

- **Browse Doctors by Specialization:** Easily find doctors based on specialization with a clean, searchable interface.  
- **Appointment Booking:** Patients can book appointments with available time slots.  
- **Responsive Design:** Fully mobile-friendly layout for an optimal experience on any device.  
- **User Profile Management:** Patients can view and edit their profile information.  
- **Authentication Ready:** Supports login and registration functionality (works with backend authentication).  

---

## 🛠 Tech Stack

- **Frontend:** React, TypeScript, TailwindCSS  
- **State Management:** Redux Toolkit  
- **Routing:** React Router  
- **API Integration:** Axios with REST API endpoints from backend  
- **Icons & UI:** Lucide React, Tailwind components
